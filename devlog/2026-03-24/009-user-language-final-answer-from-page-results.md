# 사용자 언어 기준 페이지 결과 최종답변 보강

- **ID**: 009
- **날짜**: 2026-03-24
- **유형**: 기능 추가

## 작업 요약
플로팅 챗봇의 최종답변이 페이지 결과값의 요약을 우선 사용하면서도, 사용자 질문 언어로 반드시 노출되도록 정규화 경로를 보강했다.
한국어 전용 정규화 호출을 사용자 언어 공통 정규화로 교체하고, 페이지 결과 요약이 비한국어 질문에서도 번역 단계를 거쳐 최종답변으로 나오도록 정리했다.

## 변경 파일 목록
- `src/model/struct/agent.py`
  - 페이지 결과 우선 최종답변 경로를 유지한 채 사용자 언어 공통 정규화 helper 추가
  - 페이지 결과 요약을 영어 질문에도 최종답변으로 사용할 수 있도록 변환 단계 연결
  - preview/verification 스트리밍도 사용자 언어 정규화 helper 사용
- `src/app/component.chat.floating/view.ts`
  - 사용자 질문 언어 감지 유지
