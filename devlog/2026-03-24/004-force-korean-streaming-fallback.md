# 스트리밍 답변 한국어 fallback 강제

- **ID**: 004
- **날짜**: 2026-03-24
- **유형**: 버그 수정

## 작업 요약
최종답변이 일부 예외 경로에서 영어로 노출될 수 있는 문제를 막기 위해 스트리밍 직전 한국어 정규화를 한 번 더 적용했다.
정규화 호출이 실패하거나 한국어 결과를 만들지 못하는 경우에도 페이지 결과 기반 한국어 fallback 답변으로 대체되도록 보강했다.

## 변경 파일 목록
- `src/model/struct/agent.py`
  - `_normalize_final_answer_korean()`에서 정규화 실패 시 영어 원문 대신 한국어 fallback을 반환하도록 수정
  - preview/verification 텍스트를 SSE로 내보내기 직전에 한국어 정규화를 추가
