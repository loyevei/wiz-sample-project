# 최종답변을 페이지 결과값 요약으로 우선 고정

- **ID**: 006
- **날짜**: 2026-03-24
- **유형**: 기능 추가

## 작업 요약
플로팅 챗봇의 최종답변이 검색 근거나 일반 초안으로 흐르지 않고, `read_page_results`가 반환한 실제 페이지 결과값의 요약으로 먼저 나오도록 조정했다.
페이지별 결과 JSON에서 대표 수치·유사도·비교 요약·고장 원인/조치 같은 값 중심 라인을 추출하고, 페이지 결과가 존재하면 그 요약을 최종답변 원본으로 우선 사용하도록 변경했다.

## 변경 파일 목록
- `src/model/struct/agent.py`
  - `_collect_page_result_value_lines()` 추가
  - 페이지별 결과값 중심 요약 라인 생성 로직 보강
  - `_build_page_grounded_fallback_answer()`가 실제 페이지 결과값을 중심으로 결론/근거를 구성하도록 수정
  - 페이지 결과가 있으면 `_refine_final_answer()`가 해당 요약을 최종답변으로 우선 반환하도록 변경
