# 사용자 언어 프롬프트 적용과 페이지 결과 최종답변 고정

- **ID**: 008
- **날짜**: 2026-03-24
- **유형**: 기능 추가

## 작업 요약
플로팅 챗봇의 마지막 번역 단계 의존을 줄이고, `Always answer in the user's language regardless of the context language.` 프롬프트를 시스템/정제 프롬프트에 반영했다.
또한 페이지 결과가 존재하면 그 결과값을 정리한 요약이 최종답변으로 우선 노출되도록 기존 페이지 결과 우선 경로를 유지·정리했다.

## 변경 파일 목록
- `src/model/struct/agent.py`
  - 시스템 프롬프트와 정제 프롬프트에 사용자 언어 우선 규칙 반영
  - 마지막 번역 단계 호출 제거
  - 사용자 입력 언어 감지 복원
  - 페이지 결과 요약 최종답변 우선 경로 유지
- `src/app/component.chat.floating/view.ts`
  - trace 언어 표시가 사용자 입력 언어를 따르도록 복원
