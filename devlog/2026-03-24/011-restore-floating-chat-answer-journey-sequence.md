## 작업 요약
플로팅 챗봇의 `답변 생성 과정` 영역이 최근 세부 단계와 군집 상태 위주로 확장되면서, 사용자가 익숙했던 기존 핵심 흐름이 한눈에 보이지 않던 문제를 정리했다.
프런트 표시 로직을 조정해 다시 `질문 접수 → 답변 경로 결정 → 목표 상태 → 상태 → 결과 평가 → 실행 계획 → 질문 접수 → 답변 경로 계산 → 논문 검색 실행 → 문헌 검색 완료 → 페이지 이동 실행 → 페이지 핸드오프 준비 → 근거 후보 정리 → 페이지 이동 준비` 순서 중심으로 보이도록 복원했다.
