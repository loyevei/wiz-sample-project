# 최종답변 속도 개선 및 한국어 고정

- **ID**: 017
- **날짜**: 2026-03-23
- **유형**: 기능 추가

## 작업 요약
플로팅 챗봇의 최종답변이 늦게 나오는 주원인이던 마지막 정제 LLM 호출을 크게 줄였다.
페이지 결과가 존재하면 추가 OpenAI 재호출 없이 로컬 한국어 구조화 답변으로 바로 마무리하고, 정말 필요한 경우에만 짧은 정제 호출을 사용하도록 변경했다. 또한 최종답변 언어를 한국어로 고정했다.

## 변경 파일 목록
- `src/model/struct/agent.py`
  - `_detect_language()`를 한국어 우선 출력으로 고정
  - `_needs_refinement()` 기준을 완화해 불필요한 후처리 호출 감소
  - `_build_fast_final_answer()`를 추가해 페이지 결과 기반 빠른 한국어 최종답변 생성
  - `_refine_final_answer()`에서 page_results 존재 시 추가 LLM 호출 없이 빠른 한국어 답변 반환
  - refinement 호출이 필요한 경우에도 `max_tokens`를 줄여 지연 감소
  - 메인 LLM 호출의 `max_tokens`를 2400으로 낮춰 전체 응답 지연 완화
